# erp-h 계정별 메뉴 비교 (화면 노출 · 등급)

> 작성 2026-11-16 · 비교 대상 7계정 · 메뉴 API `POST /sys/menu/list` 응답의 화면별 `authLevel`(등급)·`allow*`(기능 허용) + Aside 로 읽은 상단 탭
> **role 은 DB 에서 직접 읽지 않았다.** 화면에 로그인 id 가 안 나와, 아래 role 은 `TEST-ACCOUNTS-20261112.md`(2026-11-16 재조회)의 계정별 role 을 화면 표시 이름과 맞춰 **추정**한 것이다. 등급·메뉴 노출은 실제로 읽은 값이다.
> 등급 의미: 1 조회 · 2 저장 · 3 삭제·특수 (`auth-def/*.md` 기준, 화면마다 정의가 다를 수 있음). `·` = 그 계정 메뉴에 없음.

- 등급·메뉴는 로그인 때 계산된 결과다. 데이터 범위(법인·현장)와 화면 안의 버튼 노출은 이 비교에 들어 있지 않다. cs01 과 cs02 가 같게 나온 것이 그 예이다.
- role 이름은 추정이다. 확인하려면 DB 조회(`TEST-ACCOUNTS-20261112.md` §4 SQL)나 「사용자권한 조회」(`ca-user-role-inquiry`) 화면으로 각 계정의 role 을 읽어야 한다.
- 이름 매칭의 약점: cs02 는 화면 소속이 「건설현장」으로 나와 문서의 로그인 조직(HI1300)과 다르다. 같은 이름 계정이 더 있을 수 있다.
